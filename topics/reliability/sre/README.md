# SRE 学习指南

这是一份面向运维工程师与 SRE 的中文学习笔记，围绕 SRE 的日常关注点组织：容灾、容量、监控、调用链、变更发布、资源规划、混沌演习与故障操作，最后归纳这个岗位需要具备的能力。

- [交互式学习路线图](guide-roadmap.html)
- [返回总目录](../../../index.html)

## 学习方式

`guide.md` 是提纲式的要点集合，按「容灾 → 容量 → 监控 → 调用链 → 变更发布 → 资源规划 → 演习 → 故障操作 → 能力模型」排列：前两节先明确故障场景下的底线与容量水位，中间几节关注如何观察和改动线上系统，末尾把恢复动作与个人能力沉淀下来。

阅读时可以把每一节当成检查清单，对照自己负责的系统逐条确认：容灾是否有跨机房/跨地域的切换路径，容量水位与弹性策略是否可执行，监控指标是否覆盖性能与业务两侧，变更是否有灰度与回滚通道，混沌演习与故障操作手册是否真的演练过。
